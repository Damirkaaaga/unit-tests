# API Tests Homework

##  Downloading

```bash
npm install
npm test
```

##  Overview

This project contains automated tests for API endpoints. It is designed to validate the functionality and reliability of APIs using JavaScript and testing frameworks.

##  Project Structure

- `test/demoqa.test.js`: Contains tests for the DemoQA API.
- `test/mockApi.test.js`: Contains tests for a mock API.
- `package.json`: Includes project dependencies and scripts.

##  Getting Started

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd api-tests-homework
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run tests:
   ```bash
   npm test
   ```

##  Requirements

- Node.js (v14 or higher)
- npm (v6 or higher)
